LVM Creation:
============

we are using for flexible disk management and also we can resize and manage

Tradtional  disk crate we cannot resize

resize without downtime

easy management- we can extend and we can reduce too

we can take snapshot and easily restore
 storage we can extend whenever the filesystem is going to full

LVM Components:
Disk -> PV -> VG -> LV

check disk:
lsblk
fdisk -l
df -hT


create Physical Volume:

root@controlnode:/# pvcreate /dev/nvme2n1p1

As of now we did this as temperory mount and to add it as permanent mount we need to add the below entry in /etc/fstab otherwise when boot it will not show

before we need to take backup of fstab by cp /etc/fstab /etc/fstab.backup

then vim /etc/fstab


root@controlnode:/# cp /etc/fstab /etc/fstab.backup
root@controlnode:/# vim /etc/fstab

add this /dev/vg_prod/lv_prod    /LVM1           ext4    defaults,nofail 0 2  entry in fstab file
 
root@controlnode:/# cat /etc/fstab
LABEL=cloudimg-rootfs   /        ext4   discard,commit=30,errors=remount-ro    0 1
LABEL=BOOT      /boot   ext4    defaults        0 2
LABEL=UEFI      /boot/efi       vfat    umask=0077      0 1
# UUID=61d8fb8d-813c-41fa-830a-951af4c7c59a /newstorage xfs defaults,nofail 0 2
/dev/vg_prod/lv_prod    /LVM1           ext4    defaults,nofail 0 2


/dev/vg_prod/lv_prod = LVM path
/LVM1                                  = mount path
ext4		    = filesystem
defaults                              = default mounting options will apply
0                                             = Dump/backup
2                                             = fsck check while boot(filesystemcheck)

to verify there is no error

type mount -a

root@controlnode:/# mount -a

if no ouput is there then it is correct otherwise it has some problem



so LVM1 is created using EXT4 and it is mounted in /LVM1
