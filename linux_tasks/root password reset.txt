Root password reset
==================

while powering on 

Grub screen will be displayed so first we need to hold the grub screen by up or down arrow for any linux distribution otherwise it will automatically boot after 4 seconds

or else As soon as the machine starts booting:
- BIOS system: press and hold Shift
- UEFI system: repeatedly press Esc

above either will work in most of the case 


in grub screen 

press e

it should have more entries go to "linux" line it will be long line 

so from linux line press end

it will got to the end of the line

type-> rd.break console=tty1 selinux=0

press ctrl +x or f10

it will got to booting command list

press enter to continue

type-> mount -o remount,rw /sysroot

chroot /sysroot

passwd root

enpassword:
re-enter new pasword:


if you already mentioned in the linux line "selinux=0" dont need to do "touch /.autorelabel

lastly type-> exec /sbin/init

or else leave it

exit

exit

The actual issue is that on your current CentOS Stream 10 + dracut 107 boot environment, the emergency shell launched by rd.break is protected by sulogin, so it asks for the existing root password:
